# Yomichi implementation plan

Goal: runnable open-source alpha of the agreed full product, with a truthful parity roadmap.
Architecture: pure TS core -> DictionaryRepository -> PostgreSQL; Fastify API -> standalone Vite Playground and fetch SDK; offline streaming XML import.
Spec: ../specs/2026-10-19-yomichi-design.md
Execution: inline; user explicitly asked to start implementation and authorized repository writes.

## Global constraints
Node >=22, PostgreSQL, no runtime Python/Lisp, 500 code point input, Top-K 1..5, UTF-16 original offsets, real dictionary data only.

## Tasks
- [x] Core: types.ts, kana.ts, conjugation.ts, engine.ts. Tests in core.test.ts assert unknown preservation, supplementary characters, boundaries, alternative paths and selected verb/adjective forms. Watch failures, implement, run tests.
- [x] Dictionary: xml.ts, schema.ts, repository.ts, import.ts. Tests in dictionary.test.ts feed small documented synthetic XML through real importer + PGlite SQL, assert restrictions, gloss languages and atomic activation/rollback. Implement streaming and batched writes; production uses pg.
- [x] API/client/CLI: app.ts, main.ts, client index.ts, CLI main.ts. api.test.ts uses actual engine+repository and Fastify inject, covering invalid data, missing dictionaries, CORS, API key and response projection. No secrets in SDK/UI defaults.
- [x] Playground: responsive static Vite app, EN/ZH/JA, analysis/lookup/kanji, candidates, ruby and detail UI, developer panel. Browser smoke test real local API with test corpus only, visibly identified as a test environment.
- [x] Delivery: README, licensing, Docker Compose, CI, benchmark and parity scripts. Build, test, inspect screenshots and independent review; push verified files through GitHub connector, re-read remote commit.

## Review focus
1. Long/unknown Unicode input bounded and preserved.
2. Dictionary readings restricted to correct written forms.
3. Failed imports never replace active dataset.
4. Network failures and absent dictionary never render fabricated success.
5. Browser never receives service API secret; response data rendered with textContent.

## Execution record
Initial alpha committed as 984134a. 19 local tests and strict typecheck/build pass. Remote CI passes Node 22/24 and browser flows. See docs/VERIFICATION.md for limitations. Full parity remains a separate ROADMAP.md workstream.
